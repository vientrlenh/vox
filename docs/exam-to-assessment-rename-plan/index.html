Exam to assessment rename plan

Repository: vox · Branch: refactor/rewritten · Written 2026-11-20 · Plan status: Done

Rename the word exam to assessment everywhere it is a name in this repository: classes, files, packages, methods, attributes, variables, constants, tests and comments. The domain already calls itself “oral assessments” (AssessmentPolicy, README) while the code still says Exam, so the code and the product vocabulary disagree. This is a repo-wide rename, so AGENTS.md → Scope applies: change every occurrence, then report cross-system impact. Several parts need your approval first (public contracts, money code, security code, a migration, comment deletion); each of those is a decision below.

How the rename is done (tooling)

A scripted, whole-token rewrite run from the scratchpad (not committed, so no new file in the repository and no new dependency): git mv for paths, then token rewrite by form. No Java-aware refactoring tool is installed, so the script cannot tell a local variable examId from a REST record component examId. That is why D3 is a single choice for all camelCase/PascalCase names that reach a client or a broker. The rules are:
